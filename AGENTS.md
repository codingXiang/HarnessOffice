# HarnessOffice

Game-like AI office. Engineering work uses the Matt Pocock skills installed in `.agents/skills/`: `/grill-with-docs` → `/to-spec` → `/to-tickets` → `/implement-spec`.

## Agent skills

### Issue tracker

GitHub Issues on codingXiang/HarnessOffice. GitLab is a future secondary tracker and is not in use. See `docs/agents/issue-tracker.md`.

### Triage labels

`triage:inbox`, `triage:ready`, `triage:blocked`, `triage:done`, plus `type:bug`, `type:feature`, `type:chore`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root and ADRs under `docs/adr/`. See `docs/agents/domain.md`.
